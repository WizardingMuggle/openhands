Button to Pull Request

Pressing the button starts an OpenHands Cloud run against your repo and reports the PR back here.

One criterion per line. Sent with the user story to the agent as a single task.
The agent reviews the PR, posts its findings as a comment on it, and the page shows the verdict.
POC: JavaScript only. Bumps each dependency to the latest same-major version (4.x.x → 4.y.z) and opens a PR.
Reviews up to N open PRs (oldest first) and posts one verdict comment per PR. Nothing is merged. Run it now with the button, or nightly via NIGHTLY_PATROL on the server (see README).
Read-only analysis: the agent maps the change to affected files/components and rates the risk. No PR is opened.
