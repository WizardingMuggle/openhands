# Contributing

This is a sample contributing guide for the Button to Pull Request project.
The content here is placeholder data for testing the contribution flow.

## Getting started

1. Fork the repository.
2. Create a branch for your change: `git checkout -b my-change`.
3. Make your change and commit it.
4. Push the branch and open a pull request against `main`.

## Setup

```bash
git clone https://github.com/example/openhands.git
cd openhands
python3 server.py
```

## Guidelines

- Keep changes small and focused.
- Use clear commit messages.
- Run the app locally before opening a pull request.

## Questions

Open an issue if anything is unclear.
